RivoTalk foreground service demonstration

Actual screen recording of the signed RivoTalk alpha03 Android app (version code 3). It shows a user creating a local Bluetooth group, holding the push-to-talk control, releasing it, opening the Android home screen, inspecting the ongoing session notification and leaving the session using the notification action.

This single-emulator recording demonstrates the foreground-service lifecycle and microphone use while the app is visible. It does not demonstrate data transfer or audio exchange with a second device, or microphone recording while in the background.
